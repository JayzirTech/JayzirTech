## 🚀 Featured Projects

### 🔄 [DataMart Analytical ETL Pipeline](https://github.com/JayzirTech/datamart-analytics-etl-pipeline)
> **End-to-end analytical ETL pipeline and microservice architecture containerized with Docker.**
* **Stack:** Apache Airflow (`CeleryExecutor`), RabbitMQ, PostgreSQL (Data Warehouse), FastAPI, Docker Compose.
* **Architecture Highlights:**
  * Automated data extraction from an isolated FastAPI catalog service directly into a centralized PostgreSQL DWH.
  * Configured distributed task execution and scheduling with Celery workers and a RabbitMQ message broker.
  * Complete containerized multi-container orchestration with deterministic startup checks.

> **Dimensional Data Warehouse with automated quality gates and late-arriving event processing.**
* **Stack:** PostgreSQL, SQL, Apache Airflow, Docker, Dimensional Modeling.
* **Architecture Highlights:**
  * Designed an analytical Star Schema with **Slowly Changing Dimensions (SCD Type 2)** for historical state tracking.
  * Built ingestion handling capable of reconciling late-arriving events (>24 hours delay) without corrupting dimensional history.
  * Automated business metric resolutions and pipeline validation checks.
